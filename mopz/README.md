# AcidClean PRO

Программа расчёта дизайна МОПЗ (многостадийной обработки призабойной зоны) скважин с МГРП.

* **Входные данные.** Пользователь вводит их в интерфейсе или загружает из Excel (шаблон
  программы, выгрузки МЭР и инклинометрии).
* **Расчёт:**
  * объёмы трещины и порового пространства, промытое расстояние;
  * объёмы ГКС;
  * скин-фактор;
  * ожидаемые Qж, Qн, обводнённость, Кпрод, Рзаб;
  * дополнительная добыча нефти за 1 год;
  * режимы закачки.
* **Отчёт в PDF и XLSX** с логотипом TSS. Состав:
  * исходные данные и таблица результатов;
  * прохождение ГКС по трещинам с разлиновкой расстояния;
  * диаграмма работы скважины с потерей продуктивности;
  * прогноз на год;
  * план закачки, режим 1-й стадии и всех стадий, изменение скина;
  * выводы и рекомендации.

Методика расчёта и сверка с отчётом FracSimPRO описаны в [METHODOLOGY.md](METHODOLOGY.md).

## Запуск из исходников

```bash
cd mopz
pip install -r requirements.txt
python main.py                                  # интерфейс
python main.py examples/demo.acp         # интерфейс с примером
python main.py examples/demo.acp --pdf otchet.pdf --xlsx otchet.xlsx   # без интерфейса
python -m pytest tests -q                       # тесты и сверка с отчётом-примером
```

## Сборка exe для пользователя

**Вариант 1 — на компьютере с Windows.** Установите Python 3.10+ с python.org и запустите
`build_exe.bat`. Результат появится в папке `dist\AcidCleanPRO\`. Передайте пользователю эту
папку целиком в zip-архиве; программа запускается файлом `AcidCleanPRO.exe`. Устанавливать
Python пользователю не нужно.

**Вариант 2 — через GitHub Actions.** Workflow `.github/workflows/mopz-exe.yml` собирает exe на
Windows при каждом изменении папки `mopz/`. Его также можно запустить вручную: вкладка Actions,
«AcidClean PRO exe», кнопка Run workflow. Готовая сборка скачивается из раздела Artifacts как
`AcidCleanPRO-windows`.

## Работа в программе

1. **Файл → Новый** или **Открыть** (`*.acp`). Можно загрузить заполненный шаблон Excel:
   **Создать шаблон Excel** создаёт бланк, **Загрузить шаблон Excel** читает его.
2. **Вкладки «Скважина», «Пласт и режим», «Дизайн ОПЗ».** Заполните конструкцию, пластовые
   данные, режим до ОПЗ и параметры дизайна.
3. **Вкладка «Муфты и трещины ГРП».** По каждой муфте введите MD и параметры закреплённой
   трещины из отчёта ГРП (столбец «факт»). Галочка «Обрабатывать» включает порт в ОПЗ.
4. **Вкладка «Прогноз после ОПЗ».** Выберите экспоненту или задайте падение Qж, обводнённость
   и Рзаб по месяцам в таблице. Справа сразу обновляется график и дополнительная добыча.
5. **Вкладка «История».** Импортируйте выгрузку МЭР: нужны столбцы «Дата», «Рзаб», «Qн», «Qж»,
   «Обв.».
6. **Вкладка «Инклинометрия».** Импортируйте замеры (MD, зенит, азимут). Они нужны для расчёта
   TVD и гидростатики. Если замеров нет, задайте «TVD пласта».
7. **Рассчитать (F5)**, затем **Отчёт PDF / XLSX**.

## Структура

```
mopz/
  main.py                — запуск (интерфейс или пакетный режим)
  acidclean/models.py    — данные проекта (JSON *.acp)
  acidclean/calc.py      — расчётное ядро
  acidclean/charts.py    — графики
  acidclean/report_*.py  — отчёты PDF / XLSX
  acidclean/io_excel.py  — шаблон Excel, импорт МЭР и инклинометрии
  acidclean/gui.py       — интерфейс (PySide6)
  examples/demo.acp      — обезличенный демо-проект
  tests/                 — тесты, включая сверку с отчётом FracSimPRO
```
