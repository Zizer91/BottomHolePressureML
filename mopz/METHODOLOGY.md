# AcidClean PRO — методика расчёта

Программа выполняет расчёт дизайна многостадийной ОПЗ (МОПЗ) скважины с МГРП: объёмы ГКС
по каждой трещине ГРП, промытое расстояние, скин-фактор, ожидаемые запускные параметры,
режимы закачки и прогноз на 1 год. Код расчёта находится в `acidclean/calc.py`.

## 1. Трещина ГРП и объём кислотной композиции

Параметры каждой трещины берутся из отчёта ГРП соответствующей стадии, из последнего столбца
«факт». Расчёт ведётся по каждому порту отдельно, как в отчёте-примере.

| Величина | Формула |
|---|---|
| Объём закреплённой трещины | Vтр = 2 · Xf · H · w |
| Поровый объём пропантной пачки | Vпор = φпачки · Vтр (φпачки = 0,3) |
| Объём ГКС на порт | задан (по умолчанию 12 м³) **или** доля порового объёма: Vгкс = k · Vпор |
| Глубина проникновения ГКС (промытое расстояние) | Lпр = Vгкс / (2 · φпачки · H · w) |
| Доля промытой полудлины | η = min(1, Lпр / Xf) |

Здесь Xf — закреплённая полудлина, H — высота, w — ширина трещины, k — доля порового объёма.

Порты закачиваются от забоя к устью: ОПЗ-стадия 1 — это самая нижняя из обрабатываемых
муфт. Если порт расположен ниже полированной воронки, программа выдаёт предупреждение.
Порт можно исключить из обработки галочкой «Обрабатывать».

## 2. Скин-фактор

* **До ОПЗ** берётся по свежему ГДИС. Если ГДИС нет, принимается +0,5 (по ТЗ).
* **После ОПЗ** задаётся одним из двух режимов:
  * `fixed` — значение задаётся вручную, по умолчанию −2;
  * `calc` — расчёт по доле промытой трещины: S₁ = S₀ + (Sгрп − S₀) · η, где Sгрп —
    «идеальный геометрический» скин после ГРП из отчёта ГРП (−6,2).
* Скин скважины после ОПЗ равен среднему по обработанным портам.
* Динамика скина в ходе закачки описывается формулой S(V) = S₀ + (S₁ − S₀) · √(V/Vгкс). Она
  повторяет форму кривой из отчёта-примера: быстрое снижение в начале закачки.

## 3. Ожидаемые параметры (формула Дюпюи)

Абсолютная проницаемость и работающая толщина горизонтальной скважины с МГРП известны плохо.
Поэтому формула Дюпюи нормируется на фактический режим (входной контроль):

    Кпрод₀ = Qж₀ / (Рпл − Рзаб)
    Кпрод₁ = Кпрод₀ · (ln(Rк/rc) + S₀) / (ln(Rк/rc) + S₁)
    Qж₁ = Кпрод₁ · (Рпл − Рзаб)
    Qн₁ = Qн₀ · Qж₁ / Qж₀       (обводнённость и Рзаб не меняются)

Rк — радиус контура питания, rc — радиус скважины. Оба вводятся пользователем (по умолчанию
250 м и 0,076 м).

## 4. Входной контроль и потеря продуктивности

История (МЭР или шахматка) содержит Qн, Qж (т/сут), обводнённость и Рзаб. Расчёт:

* Qж переводится в м³/сут через плотности нефти и воды;
* Кпрод = Qж / (Рпл − Рзаб). Рпл на каждую дату берётся из истории, если там задан. Иначе
  интерполируется линейно от начального к текущему пластовому давлению;
* начальный Кпрод — медиана первых трёх замеров (так отсекаются выбросы периода освоения);
* потеря продуктивности = 1 − Кпрод тек / Кпрод нач.

## 5. Прогноз на 1 год и дополнительная добыча

Дебит падает по экспоненте с темпом D, %/мес. D задаётся вручную или оценивается по последним
12 месяцам истории добычи нефти. Если падения в истории нет, принимается 2 %/мес.

    Q(t) = Q₁ · e^(−D·t)
    ΔQдоп = Σ по месяцам (Qн₁ − Qн₀) · e^(−D·(m − 0,5)) · 30,4 сут

## 6. Режим закачки

* Расчёт ведётся с шагом 0,25 мин. Учитывается вытеснение жидкости в НКТ: башмак НКТ стоит
  на глубине муфты, перед началом закачки НКТ заполнены продавочной жидкостью.
* Забойное давление: Рзаб = Рпл + q / J(t), где J(t) = J₀ · (ln(Rк/rc) + S₀) / (ln(Rк/rc) + S(t)).
  J₀ — приемистость порта до ОПЗ. По умолчанию 4,3 м³/сут/атм — это значение даёт Рзаб ≈ 370 атм,
  как в отчёте-примере. **Его нужно уточнять тестом на приемистость.**
* Устьевое давление: Ру = Рзаб − Ргидр + Ртр.
  * Ргидр считается по TVD (инклинометрия, метод минимальной кривизны) с учётом
    распределения ГКС и продавки в НКТ.
  * Ртр — трение по формуле Дарси–Вейсбаха (Блазиус или Пуазейль), умноженное на коэффициент
    трения. Коэффициент меньше 1 означает применение понизителя трения.
* Максимальное забойное давление сравнивается с давлением ГРП.

## 7. Сверка с отчётом-примером FracSimPRO (демо-проект `examples/demo.acp`)

| Показатель | FracSimPRO | AcidClean PRO | Совпадение |
|---|---|---|---|
| Vтр, порты 2–7, м³ | 78,89 / 79,23 / 75,49 / 72,70 / 79,23 / 74,97 | 78,88 / 79,23 / 75,49 / 72,70 / 79,23 / 74,97 | точно |
| Vпор при φ = 0,3, м³ | 23,67 / 23,77 / 22,65 / 21,81 / 23,77 / 22,49 | то же | точно |
| Lпр при 12 м³, м | 116 / 111 / 112 / 116 / 111 / 117 | 116,4 / 111,3 / 112,1 / 116,4 / 111,3 / 117,6 | точно (в отчёте отброшены десятые) |
| Общая длина интервалов ОПЗ, м | 404,5 | 404,5 | точно |
| Кпрод до ОПЗ, м³/сут/атм | 0,112 | 0,112 | точно |
| Скин после ОПЗ (режим `calc`) | −3,1 | −3,0 | ≈ |
| Qж после ОПЗ, м³/сут | 38,2 | 31–33 при Rк = 250–500 м; 38,2 при ln(Rк/rc) = 6,66 | зависит от Rк/rc |
| Qн после ОПЗ, т/сут | 25,36 | 23,32 (при Qж = 38,2) | в отчёте разная плотность смеси до и после |

Расхождения возникают из-за модели симулятора FracSimPRO, формулы которой не раскрыты:

1. Чтобы формула Дюпюи дала Qж = 38,2 при S = −3,1, нужно ln(Rк/rc) ≈ 6,66 (Rк/rc ≈ 780).
   Для горизонтальной скважины это физически странно. Скорее всего, в симуляторе своя модель
   притока.
2. Нефть в отчёте посчитана с разной плотностью смеси «до» (0,878) и «после» (0,955). В
   AcidClean PRO обводнённость и плотность одинаковы до и после ОПЗ.
3. Устьевое давление на графике отчёта (70–120 атм) ниже расчётного без понизителя трения
   (≈ 200 атм): трение в НКТ 60,3×50,3 мм при 0,5 м³/мин даёт около 100 атм. Для калибровки
   служит коэффициент трения.

Тесты `tests/test_calc.py` закрепляют все совпадения из этой таблицы.
